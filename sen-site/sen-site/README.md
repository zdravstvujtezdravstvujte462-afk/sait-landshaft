# Сень — сайт ландшафтного бюро

Корень репозитория (`index.html`) — актуальная версия. Каждая прошлая версия лежит в своей папке и открывается целиком, с картинками из общей `img/`.

| Версия | Папка | Что изменилось |
| --- | --- | --- |
| v24 | `versions/v24-sen-green` | Больше зелени, карточки-листья в «Что мы делаем», лесная полоса «Год сада» |
| v23 | `versions/v23-sen-grain` | Стилистика зерна: вытянутый гротеск, сжатая антиква, подписи в углах |
| v22 | `versions/v22-sen-rebrand` | Ребрендинг в «Сень»: логотип с годовыми кольцами, светлая журнальная версия |
| v21 | `versions/v21-krona-premium` | «Крона» для премиальной аудитории: без калькулятора, пороги бюджета |
| v20 | `versions/v20-krona-palette` | Палитра камень, мох, берёза в OKLCH |
| v19 | `versions/v19-krona-skills` | Правки по навыкам interfaces: пауза слайд-шоу, ошибки формы, ховеры |
| v18 | `versions/v18-krona-start` | Исходная версия из прошлого чата |

История тех же шагов есть в коммитах: `git log`, а на GitHub — вкладка Commits.

Чтобы смотреть версии в браузере, включите GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root. Тогда версия vNN будет по адресу `…github.io/<repo>/versions/vNN-…/`.

Телефон, почта, цифры и проекты на сайте — заглушки.
